# Reference

Visual and static reference material for design and implementation work. These
files are not shipped and are not part of the build — they exist to be read,
opened in a browser, and compared against.

| File | What it is |
|---|---|
| `clear-app-reference-screens.html` | Static reference screens for the Clear member app rebuild — Home (desktop + both mobile states), limit breakdown, Savings, Earn, Activity, Send and Card. Colors, spacing, and structure are authoritative; the implementation approach is not. Written against the spec in [`../ux/clear-app-design-spec.md`](../ux/clear-app-design-spec.md). |

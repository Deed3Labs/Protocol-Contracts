# Reference

Visual and static reference material for design and implementation work. These
files are not shipped and are not part of the build — they exist to be read,
opened in a browser, and compared against.

| File | What it is |
|---|---|
| `clear-app-reference-screens.html` | Static reference screens for the Clear member app rebuild — Home (desktop + both mobile states), limit breakdown, Savings, Earn, Activity, Send and Card. Colors, spacing, and structure are authoritative; the implementation approach is not. Written against the spec in [`clear-app-design-spec.md`](./clear-app-design-spec.md). |
| [`clear-app-design-spec.md`](./clear-app-design-spec.md) | The member app's navigation and screens — what the rebuild is built to. `apps/member/src/App.tsx` follows it |
| `savings-reference.html`, `savings-prompt.md` | The Savings redesign: reference screens and the build prompt it was made from |

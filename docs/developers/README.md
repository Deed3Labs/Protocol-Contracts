# Developers

Building on Clear — integrating Pay with Clear into a shop — or working in this repository.

## Integrating Pay with Clear

The public docs are generated by [`packages/pay-docs`](../../packages/pay-docs/README.md) from the
`/v1` schemas in [`packages/public-api-contracts`](../../packages/public-api-contracts/README.md),
and served at `app.useclear.org/docs/`. Edit the generator, not the output; a test fails if the
two drift.

| | |
|---|---|
| [Quickstart](../../apps/member/public/docs/quickstart.md) | No server: the shop's checkout button opens Clear's modal |
| [Server](../../apps/member/public/docs/server.md) | With a server: the shop's server makes the payment, with `@useclear/node` |
| [Webhooks](../../apps/member/public/docs/webhooks.md) | What happened, signed — fulfil orders from these |
| [MCP](../../apps/member/public/docs/mcp.md) | `@useclear/mcp`, for a shop's agent |
| [API reference](../../apps/member/public/docs/api.md) | Every `/v1` endpoint |
| [`llms.txt`](../../apps/member/public/llms.txt) | The same, for a model to read |

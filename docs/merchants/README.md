# Merchants

Running a shop on Clear: the merchant app at `merchant.useclear.org` and the Clear for Merchants app,
for owners, managers and counter staff.

Nothing here is written yet. The developer side — payment links, checkout, the `/v1` API — is in
[Developers](../developers/README.md).

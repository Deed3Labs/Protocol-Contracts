# Contract reference

One page per deployed contract: its address on each network, every function and who may call it,
its events and its errors. Generated by [`scripts/docs/contract-reference.mjs`](../../../scripts/docs/contract-reference.mjs)
from the ABIs recorded in [`deployments/`](../../../deployments/) — what is deployed, not what the source says today —
and checked in CI, so a page can't fall behind a deployment. For how the contracts work together, read the
[protocol pages](../README.md).

**Who can call** is read from each function's access modifiers in the source. Where a function checks its
caller in its body instead, the page says so and the source has the rule. Who holds each role is chain
state, not code: see [Governance](../../governance/README.md).

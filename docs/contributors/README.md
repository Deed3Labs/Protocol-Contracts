# Contributors

For people who own land or property and want to understand how contributing it to Clear Properties,
the co-op's property company, works.

**Nothing in this section is an offer.** Clear publishes no terms, rate or projected return for a
contribution. Clear is not a contributor's tax or legal adviser, and nothing here is advice about
anyone's situation. Who may contribute, on what terms, and how a contribution is taxed are questions
for a contributor's own advisers.

**Contributing happens off the chain.** The deed, the appraisal, the shares and any distributions are
handled by Clear Properties, not by Clear's contracts. Contributor shares are not tokens.

## At a glance

| Step | Where it happens |
|---|---|
| The property goes into a nominee trust, with Clear Properties as beneficiary | Off the chain. No contract takes in or values property |
| Shares are issued, one per dollar of appraised value | Off the chain. Shares in Clear Properties are not tokens |
| Income is shared pro rata, with tax distributions | Off the chain. No contract pays holders of property shares |
| A title record on the chain for a contributed property | Not available yet |

Splitting one property into units, or into shares held as tokens, is a separate feature of the Deed
track. It is not how contributor shares work: see
[What shares are](./shares.md#not-the-same-as-fraction-tokens).
